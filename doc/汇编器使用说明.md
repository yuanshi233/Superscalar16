# Superscalar16 汇编器

`tools/assembler.py` 把 UTF-8 汇编源码编译为 Logisim Evolution 可直接读取的 `v2.0 raw` 16 位字流。处理器采用独立的指令和数据地址空间：`.text` 生成指令 ROM 文件，`.data` 生成数据 RAM 文件。两者的地址都是 16 位“字地址”，不是字节地址。

## 最快用法

```powershell
python tools/assembler.py examples/demo.s -o build/demo.hex `
  -l build/demo.lst --symbols build/demo.sym

python tools/build.py --program build/demo.hex --output build/Superscalar16.circ
```

如果源码使用了 `.data`，默认还会在源码旁生成 `源文件名.data.hex`，也可用 `-d build/data.hex` 指定路径。错误会显示文件、行号、源码行和具体原因，命令返回非零状态。

## 示例

```asm
COUNT = 5

.text
start:
    LI    r1, COUNT        ; LI 可以构造任意 16 位常量
    LI    r2, 0
loop:
    ADD   r2, r2, r1
    ADDI  r1, r1, -1
    BNEZ  r1, loop         // 标号自动换算为相对 PC+1 的位移
    SW    r2, 0(r0)        # 偏移(基址寄存器)
    HALT

.data
.org 0x20
table:
    .word 10, 20, 30
message:
    .asciz "OK\n"          ; 每个字符占一个 16 位字，末尾补 0
```

`标号:` 可和指令写在同一行。标号和常量不区分大小写；注释可用 `;`、`#` 或 `//`。数值支持十进制、`0x` 十六进制、`0b` 二进制和 `0o` 八进制。表达式支持 `+ - * / % << >> & | ^ ~`（`/` 是整数除法），`$` 表示当前字地址。

## 指令

| 类别 | 指令 |
|---|---|
| 寄存器 | `ADD/SUB/AND/OR/XOR/SLT rd, rs1, rs2` |
| 立即数 | `ADDI/SLTI rd, rs1, imm6` |
| 访存 | `LW rd, offset(base)`、`SW data, offset(base)` |
| 分支 | `BEQ/BNE rs1, rs2, target` |
| 跳转 | `JAL rd, target`、`JALR rd, rs1, imm6` |
| 其他 | `NOP`、`HALT` |

`imm6` 的范围是 -32..31，`JAL` 的 9 位相对位移范围是 -256..255。对 `BEQ/BNE/JAL` 使用标号时，汇编器自动计算 `target - (PC+1)`；直接写数值时，该数值就是原始相对位移。

便捷伪指令都只生成一个机器字：

| 伪指令 | 展开结果 |
|---|---|
| `LI rd, value` | 短常量用 `ADDI`；其他值用 `ADDI` + `ADD` 自加构造任意 16 位值 |
| `MOV rd, rs` | `ADDI rd,rs,0` |
| `B target` | `BEQ r0,r0,target` |
| `BEQZ/BNEZ rs,target` | `BEQ/BNE rs,r0,target` |
| `J target` | `JAL r0,target` |
| `CALL target` | `JAL r7,target` |
| `JR rs` | `JALR r0,rs,0` |
| `RET` | `JALR r0,r7,0` |

## 伪操作

| 语句 | 用途 |
|---|---|
| `.text` / `.data` | 切换指令/数据地址空间 |
| `.org address` | 设置当前字地址 |
| `.word a, b, ...` | 写入一个或多个 16 位字 |
| `.fill count, value` | 重复写入字，`value` 默认为 0 |
| `.zero count` / `.space count` | 保留并填 0 |
| `.align boundary, value` | 对齐到 2 的幂次边界 |
| `.ascii "text"` / `.asciz "text"` | 写字符；`asciz` 额外写终止 0 |
| `.equ NAME, expr` / `NAME = expr` | 定义常量 |
| `.include "file.inc"` | 按当前文件所在目录包含源文件 |

`.org` 可用于稀疏布局，未写入的区域会在 raw 文件中填 0；如果两段内容覆盖同一地址，汇编器会报错而不会静默覆盖。

生成完整 Logisim 工程时可直接使用：

```powershell
python tools/build.py --source examples/demo.s --output build/Superscalar16.circ
```

`.data` 会嵌入数据 RAM；如果只已有 raw 镜像，则使用
`python tools/build.py --program program.hex --data data.hex`。
